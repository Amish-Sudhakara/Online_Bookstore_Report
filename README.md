# Online_Bookstore_Report
Analysing  and comparing different models for Online Bookstore System

Branching Strategy

This project follows a simple and structured Git branching strategy.

The main branch contains the stable and approved version of the project documents.

A separate revision branch was created to modify and improve the initial requirements document. All updates and changes were performed in this branch to ensure that the main branch remained stable and unaffected.

Merging Process

After completing the updates in the revision branch, the revised requirements document (requirements_v2.docx) was finalized.

A Pull Request was then created to merge the revision branch into the main branch. The changes were reviewed and successfully merged into main.

Version History

requirements_v1.docx – Initial version of the requirements document

requirements_v2.docx – Revised version incorporating updates and improvements
